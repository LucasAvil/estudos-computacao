3. Script no final do <body>

Eu serei modificado pelo script do final do body.

✅ Boa prática: coloque seus scripts no final do <body> (ou use os atributos defer / async no <head>).

Resumo das diferenças

❌ <head> sem defer/async
→ Bloqueia a renderização da página.
→ DOM ainda não existe: getElementById() retorna null.
→ Só útil para configurações que não dependem do HTML (ex.: definir variáveis globais).
⚠️ Meio do <body> (inline)
→ Acessa apenas os elementos acima dele no HTML.
→ Bloqueia o carregamento do restante da página enquanto executa.
→ Pode causar "flash" visual e experiência ruim ao usuário.
✅ Final do <body>
→ Todo o DOM já foi construído: acessa qualquer elemento.
→ A página é renderizada antes de o JS rodar → sem bloqueio visual.
→ Forma mais simples e recomendada para scripts que manipulam o DOM.
💡 Alternativas modernas (no <head>):
<script defer src="..."> → baixa o arquivo em paralelo e executa após o HTML ser lido.
<script async src="..."> → baixa em paralelo e executa assim que possível (ordem não garantida).

Ordem de saída no console

1️⃣  SCRIPT NO <head>              → null (DOM não existe)
2️⃣  SCRIPT NO MEIO DO <body>     → encontra elementos acima, null para os abaixo
3️⃣  SCRIPT NO FINAL DO <body>    → acessa qualquer elemento da página
