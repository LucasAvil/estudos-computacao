🔁 Laços de Repetição

Estruturas que repetem um bloco de código enquanto uma condição for verdadeira.

1. for

Usado quando sabemos exatamente quantas vezes queremos repetir. Possui inicialização, condição e incremento.

// Conta de 1 até 5
for (let i = 1; i <= 5; i++) {
  console.log("Iteração:", i);
}

// Tabuada do 3
for (let i = 1; i <= 10; i++) {
  console.log(`3 x ${i} = ${3 * i}`);
}

2. for…of em Arrays

Percorre cada elemento de um array de forma simples e legível.

const frutas = ["maçã", "banana", "laranja", "uva"];

for (const fruta of frutas) {
  console.log("Fruta:", fruta);
}
// Saída: maçã, banana, laranja, uva
for…of vs for…in:
Use for...of para iterar sobre valores de arrays.
Use for...in para iterar sobre chaves de objetos.
Evite usar for...in em arrays — pode gerar comportamentos inesperados.

3. while

Repete enquanto a condição for verdadeira. A condição é verificada antes de cada iteração.

let contador = 0;

while (contador < 5) {
  console.log("contador =", contador);
  contador++;
}
// Exibe 0, 1, 2, 3, 4
⚠️ Cuidado com loop infinito!
Se a condição do while nunca se tornar falsa, o programa trrava. Sempre garanta que a variável de controle seja modificada dentro do laço.

4. do…while

Similar ao while, mas o bloco é executado pelo menos uma vez, pois a condição é verificada no final.

let tentativas = 0;

do {
  tentativas++;
  console.log("Tentativa:", tentativas);
} while (tentativas < 3);

// Saída: Tentativa 1, 2, 3
💡 Quando usar cada laço?
• for: quantidade de iterações conhecida (ex: tabuada, percorrer índices).
• for…of: percorrer todos os itens de um array/string.
• while: repetir até uma condição ser satisfeita (ex: aguardar entrada).
• do…while: executar ao menos uma vez (ex: menus, validação de entrada).
