🔍 typeof

O operador typeof retorna uma string indicando o tipo do valor de uma expressão.

1. Os tipos primitivos do JavaScript

JavaScript possui 7 tipos primitivos. Use typeof para inspecionar qualquer valor.

Tipo typeof retorna Exemplo de valor
String "string" "Olá", 'mundo', `template`
Number "number" 42, 3.14, -7, NaN
Boolean "boolean" true, false
Undefined "undefined" variável declarada mas sem valor
Null "object" ⚠️ null
Object "object" {}, [], new Date()
Function "function" function(){}, () => {}

2. typeof na prática

console.log(typeof "Weblab");     // "string"
console.log(typeof 42);           // "number"
console.log(typeof 3.14);         // "number"
console.log(typeof true);         // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object" ← comportamento histórico do JS
console.log(typeof {});           // "object"
console.log(typeof []);           // "object" ← arrays também são objetos!
console.log(typeof function(){}); // "function"

3. Usando typeof com condicionais

Muito comum verificar o tipo antes de processar um dado.

function somar(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    return "Erro: ambos precisam ser números.";
  }
  return a + b;
}

console.log(somar(3, 4));          // 7
console.log(somar("3", 4));        // Erro: ambos precisam ser números.
console.log(somar("oi", "tchau"));  // Erro: ambos precisam ser números.
⚠️ Pegadinha do null:
typeof null === "object" é um bug histórico do JavaScript que nunca foi corrigido por compatibilidade. Para verificar se algo é null de verdade, use valor === null.
💡 Como verificar se é um Array?
typeof [] retorna "object", então use:
Array.isArray([]) → true
Array.isArray({}) → false
