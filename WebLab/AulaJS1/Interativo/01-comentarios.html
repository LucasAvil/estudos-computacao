💬 Comentários em JavaScript

Comentários são trechos de código ignorados pelo interpretador — servem para explicar e documentar.

1. Comentário de linha única ( // )

Use // para comentar uma única linha ou o final de uma linha de código.

// Este é um comentário de linha única
let nome = "Maria"; // guarda o nome da usuária

console.log(nome); // exibe: Maria

2. Comentário de múltiplas linhas ( /* … */ )

Use /* */ para comentar blocos maiores de texto.

/*
  Função que calcula a área de um retângulo.
  Parâmetros:
    largura – número em metros
    altura  – número em metros
  Retorno: área em m²
*/
function area(largura, altura) {
  return largura * altura;
}

console.log(area(5, 3)); // 15

3. Comentando código temporariamente

Comentar linhas é útil para desativar código durante testes sem apagá-lo.

let resultado = 10 + 5;

// console.log("Versão antiga:", resultado * 2);
console.log("Resultado:", resultado);

Saída no console:

💡 Boas práticas:
• Comente o porquê, não o o quê — o código já mostra o que está fazendo.
• Evite comentários óbvios: // soma a + b antes de a + b não agrega valor.
• Prefira nomes de variáveis e funções descritivos para reduzir a necessidade de comentários.
