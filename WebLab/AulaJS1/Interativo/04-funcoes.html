⚙️ Funções

Funções são blocos de código reutilizáveis que realizam uma tarefa específica.

1. Declaração de Função function declaration

Forma clássica de criar uma função. Pode ser chamada antes da sua declaração no código (hoisting).

function saudar(nome) {
  return `Olá, ${nome}! Bem-vindo(a) ao JS.`;
}

console.log(saudar("Ana"));
// Saída: Olá, Ana! Bem-vindo(a) ao JS.

2. Parâmetros, Argumentos e Retorno

Funções podem receber dados (parâmetros) e devolver um resultado (return).

function somar(a, b) {
  return a + b;
}

function media(a, b, c) {
  return (a + b + c) / 3;
}

console.log(somar(4, 7));       // 11
console.log(media(6, 8, 10));   // 8

3. Expressão de Função function expression

A função é atribuída a uma variável. Não sofre hoisting — deve ser declarada antes de ser usada.

const dobrar = function(numero) {
  return numero * 2;
};

console.log(dobrar(5));  // 10
console.log(dobrar(9));  // 18

4. Arrow Function ES6+

Sintaxe mais curta para escrever funções. Muito usada em callbacks e métodos de array.

// Forma completa
const multiplicar = (a, b) => {
  return a * b;
};

// Forma resumida (retorno implícito)
const quadrado = n => n * n;
const cumprimento = () => "Olá, mundo!";

console.log(multiplicar(3, 4));  // 12
console.log(quadrado(5));       // 25
console.log(cumprimento());      // Olá, mundo!
💡 Comparação das três formas:
function soma(a, b) { return a + b; } → declaração clássica
const soma = function(a, b) { return a + b; } → expressão
const soma = (a, b) => a + b; → arrow function

As três fazem o mesmo cálculo. A arrow é mais concisa para funções simples.

5. Parâmetros Padrão ES6+

Permite definir um valor padrão para um parâmetro caso ele não seja passado.

function apresentar(nome, papel = "aluno(a)") {
  return `${nome} é ${papel}.`;
}

console.log(apresentar("Lucas"));               // Lucas é aluno(a).
console.log(apresentar("Prof. Silva", "professor")); // Prof. Silva é professor.
