📦 Arrays

Arrays são listas ordenadas que armazenam múltiplos valores em uma única variável.

1. Criação e Acesso

Arrays são criados com colchetes []. Os índices começam em 0.

const frutas = ["maçã", "banana", "laranja", "uva"];

console.log(frutas[0]);           // "maçã"  (primeiro)
console.log(frutas[2]);           // "laranja"
console.log(frutas.length);        // 4
console.log(frutas[frutas.length - 1]); // "uva" (último)

2. Adicionando e Removendo elementos

const nums = [1, 2, 3];

nums.push(4);      // adiciona no fim     → [1, 2, 3, 4]
nums.pop();       // remove do fim      → [1, 2, 3]
nums.unshift(0); // adiciona no início  → [0, 1, 2, 3]
nums.shift();     // remove do início   → [1, 2, 3]

console.log(nums); // [1, 2, 3]

Array atual: [1, 2, 3]

3. Percorrendo Arrays

const notas = [7, 9, 4, 8, 6];

// forEach – executa uma função para cada elemento
notas.forEach((nota, indice) => {
  console.log(`[${indice}] Nota: ${nota}`);
});

// for...of
for (const nota of notas) {
  console.log(nota);
}

4. map, filter e find

Métodos de alta ordem — recebem uma função como argumento e retornam um resultado.

const precos = [10, 25, 5, 40, 15];

// map → transforma cada elemento, retorna novo array
const comDesconto = precos.map(p => p * 0.9);
console.log(comDesconto); // [9, 22.5, 4.5, 36, 13.5]

// filter → filtra elementos que passam no teste
const caros = precos.filter(p => p > 15);
console.log(caros);       // [25, 40]

// find → retorna o primeiro elemento que passa no teste
const primeiro = precos.find(p => p > 10);
console.log(primeiro);    // 25

5. Outros métodos importantes

includes()

Verifica se um elemento existe no array. Retorna boolean.

indexOf()

Retorna o índice do elemento, ou −1 se não encontrar.

join()

Une todos os elementos em uma string com separador.

reverse()

Inverte a ordem dos elementos no próprio array.

sort()

Ordena os elementos (cuidado com números — precisa de comparador).

slice()

Retorna uma cópia parcial do array sem modificar o original.

splice()

Remove, substitui ou insere elementos no array.

reduce()

Acumula todos os elementos em um único valor (ex: soma total).

const letras = ["c", "a", "b"];

console.log(letras.includes("a"));  // true
console.log(letras.indexOf("b"));   // 2
console.log(letras.join(" - "));    // "c - a - b"
console.log(letras.sort());        // ["a", "b", "c"]

const nums = [1, 2, 3, 4, 5];
const soma = nums.reduce((acc, val) => acc + val, 0);
console.log(soma); // 15
💡 Resumo rápido:
• push/pop → fim do array  |  unshift/shift → início do array
• map → transforma  |  filter → filtra  |  find → busca o primeiro
• reduce → acumula num único valor  |  forEach → itera sem retorno
• Arrays têm .length e índice começa em 0.
