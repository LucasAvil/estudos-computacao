🔀 Condicionais

Estruturas que permitem executar blocos de código diferentes dependendo de uma condição.

1. if / else

Executa um bloco se a condição for verdadeira, e outro bloco se for falsa.

let idade = 17;

if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}
// Saída: Menor de idade

2. if / else if / else

Permite testar múltiplas condições em sequência.

let nota = 72;

if (nota >= 90) {
  console.log("Conceito A");
} else if (nota >= 70) {
  console.log("Conceito B");
} else if (nota >= 50) {
  console.log("Conceito C");
} else {
  console.log("Reprovado");
}
// Saída: Conceito B

3. switch / case

Ideal quando temos um valor que pode corresponder a múltiplos casos fixos.

let diaSemana = 3; // 1=Seg, 2=Ter, 3=Qua...

switch (diaSemana) {
  case 1:
    console.log("Segunda-feira");
    break;
  case 2:
    console.log("Terça-feira");
    break;
  case 3:
    console.log("Quarta-feira");
    break;
  case 4:
    console.log("Quinta-feira");
    break;
  case 5:
    console.log("Sexta-feira");
    break;
  default:
    console.log("Final de semana");
}
// Saída: Quarta-feira
⚠️ Não esqueça o break!
Sem ele, o JavaScript continua executando os casos seguintes — comportamento chamado de fall-through. O default é executado quando nenhum case corresponde ao valor.
