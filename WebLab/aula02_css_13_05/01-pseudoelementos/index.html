CSS Pseudoelementos

Selecionando partes específicas de um elemento

1. ::before e ::after

Inserem conteúdo decorativo antes ou depois do conteúdo real do elemento, sem alterar o HTML.

2. ::first-letter

Estiliza apenas a primeira letra de um bloco de texto — técnica clássica de tipografia chamada capitular.

Era uma vez um desenvolvedor web que descobriu o poder dos pseudoelementos do CSS e nunca mais voltou a usar spans desnecessários para estilizar partes específicas de seus textos. Desde então, seu código ficou muito mais limpo e semântico.

3. ::first-line

Estiliza apenas a primeira linha visível de um parágrafo (depende da largura da tela).

Esta é a primeira linha do parágrafo — ela terá estilo diferente. O restante do texto segue o estilo normal do parágrafo, sem nenhuma marcação extra no HTML. Redimensione a janela para ver o efeito mudar.

4. ::placeholder

Estiliza o texto de placeholder dos campos de formulário.

5. ::selection

Resumo dos Pseudoelementos

Pseudoelemento O que faz
::before Insere conteúdo antes do elemento
::after Insere conteúdo depois do elemento
::first-letter Estiliza a primeira letra
::first-line Estiliza a primeira linha visível
::placeholder Estiliza o placeholder de inputs
::selection Estiliza texto selecionado
