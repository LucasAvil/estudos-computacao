2. Hexadecimal — #RRGGBB

Formato de 6 dígitos hexadecimais representando vermelho (R), verde (G) e azul (B). Cada canal vai de 00 a FF. Pode ter 8 dígitos para incluir opacidade: #RRGGBBAA.

#e53e3eVermelho
#38a169Verde
#3182ceAzul
#d69e2eAmarelo
#805ad5Roxo
#1a202cQuase preto
#718096Cinza
#f7fafcQuase branco

Como funciona?

#e53e3e = R:229
##38a169 = G:161
#3182ce = B:206

💡 #FFF é o mesmo que #FFFFFF (forma abreviada com 3 dígitos)

4. RGBA — rgba(R, G, B, A)

Igual ao RGB, mas com um 4º canal: Alpha (opacidade), de 0 (invisível) a 1 (opaco). Essencial para overlays e transparências.

rgba(49,130,206, 0.9)
rgba(49,130,206, 0.6)
rgba(49,130,206, 0.3)
rgba(49,130,206, 0.1)

Muito usado em overlays escuros sobre imagens, sombras semi-transparentes e modais.

7. Variáveis CSS — var(--nome)

Defina cores em um lugar e reutilize em todo o CSS. Facilita a manutenção e a criação de temas.

/* Definindo no seletor :root (global) */
:root {
  --cor-primaria:  hsl(210, 80%, 50%);
  --cor-secundaria: hsl(270, 80%, 55%);
  --cor-fundo:      hsl(210, 30%, 97%);
  --cor-texto:      hsl(210, 30%, 20%);
}

/* Usando em qualquer lugar */
.botao {
  background-color: var(--cor-primaria);
  color: white;
}

h1 {
  color: var(--cor-secundaria);
}
