CSS — Fontes e Tipografia

font-family, Google Fonts, tamanho, peso, estilo e muito mais

1. Famílias genéricas de fonte

O CSS define 5 famílias genéricas como fallback final. Sempre termine sua lista de fontes com uma delas.

serif

O rato roeu a roupa do rei de Roma.

font-family: serif;
sans-serif

O rato roeu a roupa do rei de Roma.

font-family: sans-serif;
monospace

O rato roeu a roupa do rei de Roma.

font-family: monospace;
cursive

O rato roeu a roupa do rei de Roma.

font-family: cursive;
fantasy

O rato roeu a roupa do rei de Roma.

font-family: fantasy;

2. Google Fonts

Google Fonts oferece centenas de fontes gratuitas. Basta adicionar um <link> no <head> e usar o nome no CSS.

No <head> do HTML:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700
       &family=Playfair+Display&display=swap" rel="stylesheet">

No CSS:

body { font-family: 'Roboto', sans-serif; }
h1   { font-family: 'Playfair Display', serif; }
Roboto

Tipografia moderna para interfaces digitais.

font-family: 'Roboto', sans-serif;
Playfair Display

Elegante e clássica para títulos.

font-family: 'Playfair Display', serif;
Source Code Pro

Perfeita para exibir código-fonte.

font-family: 'Source Code Pro', monospace;
Nunito

Arredondada e amigável para textos de interface.

font-family: 'Nunito', sans-serif;

3. Tamanho da fonte — font-size

Define o tamanho do texto. Pode usar diferentes unidades (veremos mais em Medidas).

font-size: 12px — texto bem pequeno

font-size: 16px — tamanho padrão do corpo

font-size: 20px — levemente maior

font-size: 28px — subtítulo

font-size: 40px — título grande

4. Peso da fonte — font-weight

Controla a espessura do traço. Valores de 100 (fino) a 900 (negrito extremo) ou palavras-chave.

font-weight: 300 — Light

font-weight: 400 — Regular (normal)

font-weight: 700 — Bold

font-weight: 800 — ExtraBold (Nunito)

5. Estilo — font-style

font-style: normal — texto padrão

font-style: italic — itálico (Playfair Display)

font-style: oblique — inclinado mecanicamente

6. Outras propriedades tipográficas

line-height: 2

Este parágrafo tem espaçamento de linha duplo. Muito usado para melhorar a legibilidade em textos corridos.

letter-spacing: 4px

Espaçamento entre caracteres

word-spacing: 12px

Espaçamento entre as palavras do texto

text-transform

text-transform: uppercase

TEXT-TRANSFORM: LOWERCASE

text-transform: capitalize

text-decoration

text-decoration: underline

text-decoration: line-through

Link sem sublinhado (text-decoration: none)

text-align

Alinhado à esquerda (left)

Centralizado (center)

Alinhado à direita (right)

Justificado (justify) — O texto se distribui para ocupar toda a largura da linha, como em livros e jornais impressos.
